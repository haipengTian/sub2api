# 个人发布记录模板

复制到 `docs/custom/releases/<个人版本>.md` 后填写。

| 项目 | 值 |
| --- | --- |
| 个人版本 | 待填写，如 v0.2.15-custom.1 |
| 个人源代码 SHA | 待填写 |
| 官方基线 tag 与 SHA | 待核实；未融合时明确注明 |
| 二开功能与提交 | 待填写；无则注明仅基础部署 |
| 冲突处理 | 待填写 |
| SQL 迁移及向后兼容性 | 待审查，不能默认兼容 |
| 后端、前端与隔离部署验证 | 填写实际执行结果与未运行项 |
| Release URL 与镜像架构 | 构建完成后填写 |
| 个人镜像摘要 | 发布完成后填写 |
| 服务器上线、备份、网关与计费验收 | 服务器操作完成后填写 |

脚本测试通过不代表产品已构建、上游已融合或服务器已部署。
