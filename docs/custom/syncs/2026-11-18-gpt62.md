## 来源

保留 merge 历史，融合官方 `a4d3103cd5a075505da604a3d2d5243cbc51f4ea`。该提交包含稳定版 v0.2.22，以及随后新增的两笔适配：

## 冲突与恢复

- `.gitignore` 同时保留二开文档和上游新增文档。
- Vue I18n 使用上游版本范围和锁文件解析值，保留二开安全覆盖项与运行时构建别名。
- 图片账号测试同时保留上游 GPT Image 参数修复与 Muse 回归；兼容图片模型继续发送 b64_json，GPT Image 不发送 response_format。
- 设置页采用上游保存浮标，保留 Credit 的 settings-save-bar 样式入口；订阅卡片保留上游测试。
- VERSION 设置为个人版本，保留可复用 CI、独立发布产物和个人镜像通道，同时纳入上游 Go 1.27.4 / Node.js 24。
- GitHub 禁用了 fork 的 Actions，本次恢复现有工作流。自动协调器补齐手工发布后的状态对账，并保留发布失败后的重试状态。

## 数据库与服务器升级

相对 v0.2.19 新增 5 个 SQL 文件：249 MCP OAuth 表、249 usage_logs 成本覆盖索引、250 缓存写入 TTL 字段、251 强制 Ultra Fast 字段、251 分组日汇总失效函数与状态字段。成本索引用 CONCURRENTLY 创建，大表首次启动可能耗时；汇总迁移会替换数据库函数，不能仅凭新增列判断旧版可直接回滚。

使用 server-ops 的 update.sh 在维护窗口备份并升级。MCP 默认关闭，未配置 MCP_PUBLIC_URL 时不启用。保留原数据库、密钥和个人配置；数据库兼容性未经单独确认时不使用 --database-compatible 回滚。真实模型权限、上游额度与计费需在服务器升级后验收。
