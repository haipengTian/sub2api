# v0.2.19-custom.3

为 Muse 视频补齐后台账号测试界面。沿用 v0.2.19-custom.2 的图片、异步视频网关和前端安全升级，不更换官方基线。

## 视频测试不再走聊天

- 在账号测试中选择 `muse-video` 或映射到它的模型，自动显示视频提示词，不显示聊天常规 / Compact 模式。
- 支持精确别名和最长前缀通配符映射，默认请求约 6 秒、480p、16:9 的视频；管理端可上传一张参考图。
- 创建任务后显示任务 ID、上游真实状态和进度，完成后在弹窗中播放，并自动滚动到预览位置。
- 关闭、切换账号或卸载弹窗时停止等待，不自动重提任务；每次重新打开清除参考图，避免跨账号复用。
- 等待最长 6 分钟；断线、失败、非法返回和预览下载失败均明确显示错误，不标记为成功。
- 生成请求不自动重试。预览最多 32 MiB，只从配置的 Muse2API 主机下载 `/v1/media/` 文件，所有请求禁止重定向。
- CSP 仅补充 `media-src 'self' data:`，使默认和旧自定义策略允许内嵌视频；不放开脚本来源。
- 保留既有聊天、图片、Grok 和 Compact 测试入口。

## 使用与费用

打开 Muse2API 账号的“测试账号连接”，选择视频模型，填写提示词并点击“开始测试”。账号测试直接消耗上游生成额度，不经过用户 API Key 扣费。分组路由与用户计费仍通过视频网关 API 单独验收。关闭窗口不会取消已经提交的上游任务，请勿重复提交。

配置和视频 API 调用见 [通过 Sub2API 使用 Muse 图片和视频](../muse-images.md)。

## 验证与发布

已在本地对账号测试、失败与取消、精确/通配符映射及 CSP 做定向回归，并检查中英文、深色模式和手机宽度。使用模拟上游和本地样片验证视频播放，未消耗真实 Muse 生成额度。

本次发布以该标签对应的 GitHub Actions 完成结果为准；完整构建和镜像信息在正式发布后补充。

## 服务器更新

待 `v0.2.19-custom.3` Release 成功后执行：

```bash
cd /opt/server-ops/sub2api
bash update.sh ghcr.io/haipengtian/sub2api:0.2.19-custom.3
bash status.sh
```

本次无新增 SQL 迁移。脚本会暂停应用、备份并检查新容器健康状态，有短暂中断。不需要重建 PostgreSQL / Redis 或修改 Nginx。

升级后刷新页面，在账号测试中选择 `muse-video`，验证一次生成、进度和播放；同时核对原有图片、聊天和实际用户请求计费。尚未连接或修改生产服务器。
