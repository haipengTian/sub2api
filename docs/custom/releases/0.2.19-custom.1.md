# v0.2.19-custom.1

融合官方 v0.2.17、v0.2.18、v0.2.19，保留现代、经典、Credit 三套皮肤及个人 custom 更新、发布通道。

## 来源与变化

- 官方稳定基线：`v0.2.19`，提交 `dece26153621959ccd7635814f4b2d08304e681a`。
- 发布源代码：`c7cdce5e4583f2286f6384bcba0b15142a789ebb`；通过真实 merge 保留双方历史。
- 新增按操作与资源范围授权的管理员 API 密钥，保留旧管理员密钥及二次验证入口。
- 新增分组按图片张数计费选项，修复多图、流式响应与缓存 token 的计费问题。
- 更新 Gemini 默认模型目录，增加 GPT-6.1 Terra 支持，完善 Grok 模型目录同步与诊断。
- 修复支付确认、退款与恢复流程，支付页移除 URL 中的 client_secret。
- 设置页融合保持 Credit 布局，新管理员密钥组件完整宽度，旧密钥可折叠查看。

完整融合与冲突处理见 [同步记录](../syncs/2026-10-29-v0.2.19.md)。

## 服务器更新

由服务器操作者执行：

```bash
cd /opt/server-ops/sub2api
bash update.sh ghcr.io/haipengtian/sub2api:0.2.19-custom.1
bash status.sh
```

更新脚本会先拉取固定镜像，再暂停应用、备份并检查新版本健康状态，有短暂中断。
升级后检查登录、三套皮肤切换、真实普通与流式模型请求、计费，以及在用的支付入口。
本次未操作生产服务器，部署及真实业务验收由服务器操作者完成。
