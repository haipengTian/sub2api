# v0.2.16-custom.3

本次在 v0.2.16-custom.2 基线上新增 Credit 风格，并完善首页、登录、图表与公共组件展示。

## 来源与范围

- 沿用 v0.2.16-custom.2 的官方融合基线；本次不引入额外上游提交。
- 新增 Credit 皮肤，现代与经典皮肤保留，默认仍为现代；已有外观偏好不覆盖。
- Credit 首页、认证页、用户及管理员界面、紧凑表格、分页、侧栏收起与内容宽度切换。
- 图表配色、数字演示、加载反馈与公共组件动效适配深色及减少动态效果。
- 本地字体与第三方许可随网站、嵌入式前端和镜像分发。
