# v0.2.22-custom.1

融合官方 v0.2.22 与后续 GPT-6.2 适配，保留现代、经典、Credit 皮肤和 Muse 图片、异步视频及账号测试。

## GPT-6.2

支持模型 gpt-6.2-sol、gpt-6.2-astra，补齐 Codex 模型描述、推理强度与采样参数处理、Responses 工具调用、缓存和长上下文计费，以及 Fast / Ultra Fast 档位与 OAuth 套餐权限。实际可调用的模型和档位仍由上游账号权限决定。

升级后检查账号模型白名单、分组/渠道定价和客户端模型选择；添加所需的 6.2 模型，分别验证普通请求、流式和工具调用，再核对用量与扣费。不把新模型映射到旧模型冒充成功。

## 自动更新

恢复 GitHub fork 的现有 Actions。之后继续每六小时检查官方稳定版，自动融合、验证和发布；真实代码冲突或上游工作流变更仍交维护者处理。手工发布后重新核对官方历史和个人 Release，清除已解决的冲突报告，并保留失败发布的恢复入口。

## 升级

本版本包含数据库迁移，详情见 [同步记录](../syncs/2026-11-18-gpt62.md)。首次建索引可能延长启动时间；在维护窗口执行，update.sh 会暂停应用并备份：

